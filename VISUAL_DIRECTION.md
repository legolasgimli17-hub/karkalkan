# KârKalkan Visual Direction

KârKalkan should look like a financial control room, not a generic marketplace dashboard.

## Identity

- Obsidian / charcoal foundation
- Copper / amber for money-flow emphasis
- Ice blue for evidence and verified-data emphasis
- Red only for genuinely important risk states
- No competitor-green visual identity

## Visual hierarchy

1. What is happening now?
2. How much of the number is evidenced?
3. Where can money be leaking?
4. What should the seller do next?

## Data honesty

- Decorative diagrams must not look like real seller data.
- Charts that encode money must be built from actual rendered dashboard values.
- Unknown values stay unknown; visual polish must never turn null into zero.
- Confidence graphics represent financial-data confidence, not business success.

## Components

- Process orbit on sign-in / empty state
- Real daily sales vs known-cash area chart
- Financial Data Confidence ring + radar
- Money Bridge / flow visualization
- Money Leak Radar with explicit note that spatial dots are decorative
- Visual empty states that explain what appears after a store is connected

The goal is a recognisable KârKalkan product language that remains distinct from KarPanel and other Trendyol seller dashboards.
